Instalação via APT

Configure o repositório uma vez e use apt normalmente para instalar e receber atualizações automáticas.

1
Adicionar a chave GPG do repositório 
curl -fsSL https://revdf.github.io/anonimax/KEY.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/anonimax.gpg
2
Adicionar o repositório às fontes do APT 
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/anonimax.gpg] \
  https://revdf.github.io/anonimax stable main" \
  | sudo tee /etc/apt/sources.list.d/anonimax.list
3
Instalar 
sudo apt update
sudo apt install anonimax-cli        # CLI + daemon
sudo apt install anonimax-gui        # Interface gráfica (opcional)

Verificar ambiente antes de instalar

Rode o script de diagnóstico para confirmar que todas as dependências estão presentes:

curl -fsSL https://raw.githubusercontent.com/revdf/anonimax/master/anonimax-doctor.sh | bash

Remover o repositório

sudo rm /etc/apt/sources.list.d/anonimax.list \
         /usr/share/keyrings/anonimax.gpg
sudo apt update
